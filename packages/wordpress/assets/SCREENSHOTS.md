# Screenshot files for WordPress.org

Place the following files in this directory before submitting to WordPress.org SVN:

| File | Matches readme.txt caption |
|---|---|
| `screenshot-1.png` | Chat UI (wp-admin → phpClaw → Chat) |
| `screenshot-2.png` | Settings page (wp-admin → phpClaw → Settings) |
| `screenshot-3.png` | About page (wp-admin → phpClaw → About) |
| `screenshot-4.png` | Guide page (wp-admin → phpClaw → Guide) |
| `screenshot-5.png` | Analytics page (wp-admin → phpClaw → Analytics) |
| `screenshot-6.png` | Site Health (wp-admin → Tools → Site Health → Info) |

Recommended size: 1200×900 px, PNG, <1 MB each.
Note: assets/ ships inside the plugin ZIP. WordPress.org also needs these files uploaded
      separately to the SVN assets/ directory, which is what serves them on the listing page.
